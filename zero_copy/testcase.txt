 TEST CASES  (10 cases)  -  Multi-threaded File Download

All "Actual output" blocks below are REAL output captured from running
the program (not typed by hand). Your numbers for time, MB/s and the
ORDER of the worker lines will be different on your machine: that is
normal. What must be the same is listed under "Expected result".

Extra automatic check: "java TestRunner" runs 84 more checks
(see HOW_TO_RUN.txt). These 10 cases are the ones you run by hand and
can show in your report / demo.


PREPARATION (do once)
---------------------------------------------------------------------
1. Compile (in the project folder):
       javac *.java
2. Create the 100 MB test file (same content on every computer):
       java MakeTestFile shared/test.bin 100
   Its SHA-256 must always be:
       be09bb617fc7866b59acce2bd709eef846ed928edf541c30279f96e611e23584
   To check it yourself:
       Windows (cmd)        : certutil -hashfile shared\test.bin SHA256
       Windows (PowerShell) : Get-FileHash shared\test.bin -Algorithm SHA256
       Linux / macOS        : sha256sum shared/test.bin
3. The folder "shared" must contain these 3 files:
       hello.txt        44 bytes         (provided)
       sample_odd.bin   1000003 bytes    (provided, size NOT divisible by 10)
       test.bin         104857600 bytes  (created in step 2)
4. Start the server in Terminal 1 and leave it open:
       java Server
   You should see:  [server] listening on port 5000, sharing folder: ...
5. Open Terminal 2 (same folder) and run the test cases below in order.

Range rule used by the client (to predict the expected output):
    chunk = size / workers ; worker i starts at i * chunk ;
    the LAST worker takes the remainder (size - its offset).
